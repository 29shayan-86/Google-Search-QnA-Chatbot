# 🤖 Ask Buddy - AI QnA Bot

An AI chatbot built using **LangChain**, **Groq**, and **Streamlit**.

## 🚀 Features

- AI-powered chatbot
- Interactive chat interface
- Fast inference with Groq
- Built using LangChain

## 🛠 Tech Stack

- Python
- Streamlit
- LangChain
- Groq
- python-dotenv

## Installation

Clone the repository

```bash
git clone https://github.com/29shayan-86/Ask-Buddy-AI.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=your_groq_api_key_here
```

Run

```bash
streamlit run apps/qna_chatbot.py
```
